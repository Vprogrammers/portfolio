# Freezer case

An ice cream shop's tablet, on a 16 s timeline. Two display cases hold rows of tubs whose levels run down during the day. One tub drains almost dry and flashes red, and the kitchen gets a push to make that flavour. The fresh tub then refills.

Data: `brand`, `add`, `cases` (`name`, `tubs`: `name`, `color`, `level` as a %, `low`; seven per case), `push` (`app`, `title`, `body`). The parent sets `--case-h`, `--case-x` and `--case-y`.
